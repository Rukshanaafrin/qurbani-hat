## 📖 Project Overview
QurbaniHat is a modern livestock marketplace where users can explore animals like cows and goats for Qurbani.  
Users can view detailed information and book animals after authentication.

---

## ✨ Key Features

- 🔐 Firebase Authentication (Email & Google Login)
- 🐐 Browse All Animals
- 📊 Sort animals by price
- 📄 Animal Details Page (Private Route)
- 📝 Booking Form with success toast
- 👤 User Registration & Login System
- 🧭 Protected Routes
- 📱 Fully Responsive Design
- 🎨 Modern UI with Tailwind CSS & DaisyUI
- 🔔 Toast Notifications
- ⚡ Loading state added
- ❌ Custom Not Found Page
